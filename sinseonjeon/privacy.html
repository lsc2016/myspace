개인정보처리방침

시행일: 2026년 10월 17일

1. 앱 소개

신선전(이하 "앱")은 운영자 본인의 유튜브 채널에 영상을 올리고 관리하기 위한 개인용 도구입니다. 운영자 외의 사용자를 대상으로 하지 않습니다.

2. 사용하는 정보

앱은 사용자가 구글 계정으로 로그인해 허용한 범위 안에서만 다음 정보를 사용합니다.

  • 유튜브: 채널 정보, 영상 업로드와 수정, 재생목록 관리, 조회수 등 채널 통계 확인
  • 구글 드라이브: 업로드할 영상과 관련 파일 읽기, 앱이 만든 파일 저장

3. 정보의 보관

구글 로그인으로 받은 접근 권한(토큰)은 운영자의 컴퓨터에만 저장됩니다. 앱은 별도의 서버를 두지 않으며, 수집한 정보를 외부에 보관하지 않습니다.

4. 제3자 제공

앱은 사용자의 정보를 판매하거나 제3자에게 제공하지 않습니다. 정보는 위 2항의 기능을 수행하는 데에만 사용합니다.

5. 구글 API 서비스 사용자 데이터 정책 준수

앱이 구글 API로부터 받은 정보를 사용하고 다른 앱으로 전송할 때는 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 앱은 YouTube 서비스 약관에 따라 YouTube API 서비스를 사용하며, 구글의 개인정보 처리에는 Google 개인정보처리방침이 적용됩니다.

6. 권한 철회와 삭제

언제든지 구글 계정의 서드파티 액세스 설정에서 앱의 접근 권한을 철회할 수 있습니다. 철회하면 앱은 더 이상 계정 정보에 접근할 수 없으며, 운영자의 컴퓨터에 저장된 토큰도 삭제를 요청할 수 있습니다.
